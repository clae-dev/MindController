# 마음 들여다보기 · MindController

청소년 행사·부스 체험용 **웹 기반 표정 분석 서비스**입니다. 웹캠 앞에서 잠깐이면 표정과 심박을 읽어 두 가지 체험을 전해줍니다 — 마음 상태를 살피는 **마음 분석**과, 평소 표정 대비 얼마나 긴장하는지 보는 **긴장 감지**.

**라이브**: https://mindcontroller-theta.vercel.app

> 성빈센트청소년회 · 한국사회공헌협회 청년챔프단 **Butterfly**가 함께합니다.

## 🎯 두 가지 모드

### 🌿 마음 분석 (스트레스·감정)

- **10초 표정 분석** — 얼굴이 인식되면 자동으로 10초간 분석, 버튼 한 번이면 끝
- **7가지 감정 인식** — MediaPipe 블렌드셰이프(얼굴 근육 52종)로 행복·슬픔·분노·놀람·평온·불쾌·불안을 측정
- **심박수 추정 (rPPG)** — 손 대지 않고 웹캠만으로 이마·볼 피부의 미세한 맥동을 분석해 BPM 추정 (참고·재미용)
- **스트레스 지수 (0~100)** — 감정 조합으로 계산, 낮음/보통/높음 3단계 판정
- **풍부한 결과 화면** — 강도별 표정 묘사("잔잔한 미소가 머무는 얼굴"), 감정 분포 차트, 맞춤 조언
- **오늘의 한마디** — 한국 명언·드라마 대사·속담 등 50여 개 문구를 스트레스 수준과 감지된 감정에 맞게 랜덤 제공 (연속 반복 방지)
- **측정할수록 정확해짐** — 측정마다 익명 통계를 기기에 누적해 분포 기반으로 판정을 자동 보정

### 🔍 긴장 감지 (베이스라인 대비 긴장도)

먼저 4초간 평소 표정을 익힌 뒤, 그에 비해 얼마나 긴장하는지 실시간 게이지로 읽어줍니다. **재미로 보는 추정이며 실제 거짓말 판별이 아닙니다.** 세 가지 하위 모드가 있어요.

- **자유 측정** — 말하거나 가만히 있는 동안 긴장도를 실시간 게이지(0~100)로 표시
- **질문 챌린지** — 질문 4개에 답하는 동안 어떤 질문에서 가장 흔들렸는지 막대그래프로 비교
- **웃음 판별** — 진짜 웃음인지 억지 웃음인지 판정 (눈가 근육까지 동반되는 **Duchenne 미소** 기준)
- **다중 신호 종합** — 표정 긴장, 미세표정의 흔들림, 깜빡임 변화, 시선·고개 움직임, 심박 상승을 합산하고 신호 신뢰도를 함께 표시

> 두 기능 모두 **영상은 저장되지 않고 브라우저 안에서만 처리**되며, 서버로 전송되지 않습니다.

## 🎨 UI/UX

- 하늘 + 풀밭 + 축제 가랜드 배경에 관람차·회전목마·뛰노는 아이들 이모지가 움직이는 장면
- 아이보리 에디토리얼 카드 디자인 (Noto Serif KR 세리프 헤딩, Pretendard 본문)
- Google Noto Animated Emoji를 **Lottie 벡터**로 렌더링 (webp 대비 약 10배 가벼움)
- 결과 숫자가 0에서 또르륵 차오르는 카운트업 연출 (`useCountUp`)
- 모바일 대응, `prefers-reduced-motion` 지원

## 🛠 기술 스택

- **Frontend**: React 19 + TypeScript + Vite
- **얼굴 인식**: MediaPipe FaceLandmarker (WASM, 블렌드셰이프 출력) — 브라우저 내 추론
- **심박 추정**: POS(Plane-Orthogonal-to-Skin, Wang et al. 2017) 기반 rPPG
- **애니메이션 이모지**: Noto Animated Emoji (Lottie) + lottie-web
- **배포**: Vercel (GitHub `master` push 시 자동 배포)

## 🚀 사용 방법

1. 브라우저에서 접속 후 시작 화면에서 **마음 분석** 또는 **긴장 감지** 선택
2. 카메라 권한 허용
3. 안내에 따라 측정 (마음 분석은 자동 10초, 긴장 감지는 4초 베이스라인 후 모드별 진행)
4. 결과 확인
5. "다시 해볼래요" 버튼으로 처음으로 돌아가 다음 사람이 이용

## 📊 분석 로직 개요

### 마음 분석
1. 100ms마다 프레임에서 얼굴 랜드마크 + 블렌드셰이프 추출 (딥러닝)
2. 블렌드셰이프 가중 조합으로 감정 점수 산출 — 예: 행복 = 미소×1.2 + 볼 올라감×0.4
3. 10초 평균 → 스트레스 지수 = 슬픔+분노+불쾌+불안×0.8+놀람×0.3−행복×0.5. 이마·볼 ROI 색 변화로 심박(POS rPPG) 별도 추정
4. 기기 누적 분포(15회 이상)에 비추어 z-점수 보정 후 단계 판정 (0~32 낮음 / 33~65 보통 / 66~100 높음)

### 긴장 감지
1. 4초간 평소 표정으로 개인 베이스라인 수립
2. 측정 중 표정 긴장·미세표정 흔들림·깜빡임 변화·시선/고개 움직임·심박 상승을 종합해 긴장 게이지(0~100) 산출
3. 신호가 약하거나 움직임이 많으면 신뢰도를 낮추고 안내
4. 질문 모드는 문항별 최고 긴장값을 비교, 웃음 모드는 눈가 근육 동반 여부로 Duchenne 점수 산정

## 📝 주의사항

- **카메라 필요** — 마이크는 사용하지 않습니다
- **HTTPS 필수** — 웹캠 권한 때문에 로컬(`localhost`) 또는 HTTPS 환경에서만 동작
- **밝은 조명** 권장 — 표정 인식·심박 추정 정확도에 영향
- 심박·긴장·웃음 판별은 모두 **재미·참고용 추정**이며 의료/진단 용도가 아닙니다
- 최신 Chrome/Edge/Safari 권장

```bash
vercel --prod            # 수동 배포도 가능
```
